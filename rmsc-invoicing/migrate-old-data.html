Move data from the old invoicing app

The old app kept invoices inside the browser. This page saves them into a backup file that the new app can read.

  1. Put this file in the same folder as the old RMSC Invoicing.html file.
  2. Open it in the same browser you used for the old app (for example Chrome).
  3. Tap Save backup file below.
  4. In the new app go to Settings → Backup → Restore backup and pick that file.
